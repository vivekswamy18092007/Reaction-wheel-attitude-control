GLOBAL STABILITY: NOT ESTABLISHED (alpha < 0)
  mu = 0: requires K^-1 = alpha*J + beta*I with alpha, beta >= 0.
        fitted alpha = -2.418923e+04
        fitted beta  = +4.114232e+02
        relative residual |K^-1 - (alpha*J + beta*I)| = 3.78e-16
        K^-1 is exactly in span{J, I} (residual at machine
        precision) but alpha < 0, so it falls outside the
        alpha, beta >= 0 cone the Sec. III proof requires.
        Note this is structural, not a tuning artifact: the
        least-squares fit in design() matches 1/J_i against
        a*J_i + b, and 1/J_i is decreasing in J_i, so the
        slope is negative for ANY J with distinct moments --
        including the paper's own Sec. VI example.
        K = K^T > 0 still holds, so this is 'unproven by this
        route', NOT 'shown unstable'. Verify convergence
        empirically and say so explicitly in the report.
